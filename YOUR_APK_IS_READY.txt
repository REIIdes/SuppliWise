📲 HOW TO INSTALL ON YOUR PHONE:

OPTION 1: USB Transfer (Easiest)
1. Connect phone to PC via USB cable
2. Copy app-debug.apk to your phone's Downloads folder
3. On phone: Open Files/Downloads
4. Tap app-debug.apk
5. Enable "Install from unknown sources" if prompted
6. Tap "Install"
7. Open SuppliWise!

OPTION 2: Google Drive/Dropbox
1. Upload app-debug.apk to Google Drive or Dropbox
2. On phone: Open Drive/Dropbox app
3. Download app-debug.apk
4. Tap to install
5. Enable "Install from unknown sources" if prompted

OPTION 3: Email
1. Email app-debug.apk to yourself
2. On phone: Open email
3. Download attachment
4. Tap to install

🔒 SECURITY NOTICE:

When installing, Android will warn:
"For your security, your phone is not allowed to install 
unknown apps from this source"

This is NORMAL for apps not from Google Play Store.

To allow installation:
1. Tap "Settings"
2. Enable "Allow from this source"
3. Go back and tap "Install"

This is safe - it's YOUR app that YOU built!

🔄 TO UPDATE THE APP (After making changes):

1. Build web assets:
   cd my-react-app
   npm run build

2. Sync to Android:
   npx cap sync android

3. Build new APK:
   cd android
   .\gradlew.bat assembleDebug

4. Install new APK on phone (overwrites old version)
